Vị trí: Java Backend Fresher (Fintech & E-Wallet Payment API)
Cấp bậc: Fresher (0 - 1 năm kinh nghiệm)
Lĩnh vực: Công nghệ Tài chính & Thanh toán điện tử (Fintech / Payment Gateway)

Mô tả công việc:
- Tham gia phát triển các dịch vụ Backend cốt lõi cho ứng dụng Ví điện tử và Cổng thanh toán trực tuyến trên nền tảng Java 17 và Spring Boot.
- Xây dựng các API chuyển tiền, nạp/rút tiền, đối soát giao dịch và lịch sử biến động số dư với yêu cầu cao về tính toàn vẹn dữ liệu (ACID).
- Quản lý giao dịch cơ sở dữ liệu nghiêm ngặt bằng cơ chế @Transactional của Spring, xử lý đồng thời (Concurrency Control) thông qua Optimistic Locking (@Version) hoặc Pessimistic Locking.
- Tích hợp bộ nhớ đệm phân tán Redis để lưu trữ phiên giao dịch ngắn hạn, mã OTP xác thực và giảm tải truy vấn cơ sở dữ liệu PostgreSQL.
- Kết nối và xử lý Webhook callback từ các cổng thanh toán bên thứ ba (như VNPay, Momo, Stripe hoặc PayPal REST API).

Yêu cầu bắt buộc (Mandatory Skills):
- Thành thạo ngôn ngữ lập trình Java (Java 11/17) và nắm rõ cơ chế quản lý bộ nhớ, đa luồng cơ bản.
- Kinh nghiệm thực tế phát triển RESTful Web Services với Spring Boot và Spring Data JPA.
- Hiểu sâu về quản lý Transaction trong cơ sở dữ liệu quan hệ (PostgreSQL/MySQL) và cách xử lý rollback khi xảy ra lỗi nghiệp vụ.
- Đã từng tích hợp và thao tác với Redis Cache (Spring Data Redis / Lettuce / Jedis) trong dự án thực tế.

Yêu cầu ưu tiên / Điểm cộng (Preferred Skills):
- Đã từng triển khai tích hợp cổng thanh toán (VNPay, PayPal, Stripe) và xác thực chữ ký số (HMAC-SHA256 / Webhook verification).
- Hiểu biết về bảo mật API (Spring Security, Rate Limiting, mã hóa dữ liệu nhạy cảm BCrypt/AES) và đóng gói Docker.
