\section{Approach and Study Design}
\label{sec:approach}

To separate chunk boundaries from contextual metadata, we employ a $2 \times 2$ factorial design evaluated across three retrieval tiers, governed by a frozen analysis protocol.

\subsection{Corpus, Candidate Space, and Curation}
\label{sec:approach:corpus}
Our corpus comprises 40 open-source GitHub repositories (20 Java Spring Boot, 20 React/TypeScript) spanning 189 source files. 
As documented in \texttt{sampling\_frame\_log.json}, repositories were curated from public GitHub projects exhibiting production architectural patterns (controllers, services, DTOs, custom hooks, Redux stores, UI components). 
Repository licenses encompass 19 MIT (47.5\%), 16 Public GitHub default copyright (40.0\%), 4 Apache-2.0 (10.0\%), and 1 GNU AGPL-3.0 (2.5\%); all source text is redistributed in our replication package under original author copyright.
Queries represent 25 public job descriptions (15 Java backend, 10 React/TypeScript frontend) with mandatory technical skill requirements extracted via a frozen prompt on \texttt{gemini-1.5-flash} (\texttt{queries\_frozen.json}). 
For each query, retrieval evaluates across the full candidate space: 434 chunks for line conditions and 438 chunks for AST conditions (872 total chunks in the corpus).

\subsection{Factorial Conditions and Retrieval Pipeline}
\label{sec:approach:factorial}
We evaluate two orthogonal dimensions:
\textbf{Chunking Strategy:} \textit{Line-window chunking} slices files into 50-LOC windows with 10-LOC overlap (step 40 LOC, minimum 6 LOC; 434 chunks). 
\textit{AST-first chunking} uses Tree-sitter parsers expanded to modern language constructs (Java methods, constructors, records, interfaces, enums, annotated classes; React/TS components, hooks, wrappers, slices, types; $6 \le \text{LOC} \le 85$). 
Files lacking extractable units fall back to 50-LOC windows (target $<10\%$; measured $0.0\%$, 0/438 chunks). 
AST preserves syntactic boundaries in $87.2\%$ of chunks vs. $44.0\%$ for line windows (cutting boundaries in $56.0\%$).
\textbf{Context Header Condition:} \textit{Without Header} contains raw code. \textit{With Header} prepends: \texttt{// File: <path> \textbackslash n // Class: <name> \textbackslash n // Method: <name> \textbackslash n // Lines: <start>-<end>}.
\textbf{Retrieval Tiers:} (1)~\textit{BM25} (lexical baseline). (2)~\textit{Dense} BAAI/bge-m3~\cite{chen2024bgem3} (1024d embeddings, cosine similarity). (3)~\textit{Reranking} BAAI/bge-reranker-base~\cite{xiao2023cpack} (cross-encoder rescoring top-20 dense candidates).

\subsection{Unified Blinded Pooling Protocol}
\label{sec:approach:pooling}
To prevent system bias, we executed a single-wave Cranfield/TREC pooling protocol: top-5 candidates from all 12 systems (BM25, Dense, Rerank $\times$ 4 conditions) were pooled, yielding 1,500 candidates deduplicated to 882 unique pairs. 
Two SE annotators independently labeled all 882 pairs on a 3-point relevance scale (0: irrelevant, 1: partially relevant, 2: highly relevant). 
Annotation was $100\%$ blinded to strategy, header condition, tier, rank, and score. 
Inter-annotator agreement reached almost perfect concordance: quadratic-weighted Cohen's $\kappa = 0.9822$ (linear $\kappa = 0.9634$, unweighted $\kappa = 0.9453$, $98.07\%$ exact agreement). 
The 17 disagreements were adjudicated by a Lead Adjudicator using standardized rubrics. 
Pooling top-5 across all systems yields complete coverage ($\text{Judged@3} = 100.0\%$, $\text{Judged@5} = 100.0\%$) and zero orphaned pairs.

\subsection{Evaluation Metrics and Hypothesis Testing}
\label{sec:approach:metrics}
The primary metric is $\text{NDCG@10}$ (linear gain $\mathrm{rel}_i/\log_2(i+1)$). 
Unjudged items receive relevance 0; we also report binary preference (\texttt{bpref})~\cite{buckley2004bpref}, $\text{NDCG@1}$, $\text{MRR@10}$, and $\text{Judged@10}$. 
The pre-registered confirmatory family tests four paired comparisons over $N=25$ queries at the rerank tier: \textbf{Comp 1} (\astH\ vs. \lineN), \textbf{Comp 2} (\astN\ vs. \lineN), \textbf{Comp 3} (\astH\ vs. \astN), and \textbf{Comp 4} (\lineH\ vs. \lineN) via two-sided Wilcoxon signed-rank tests~\cite{wilcoxon1945individual} with Holm-Bonferroni correction~\cite{holm1979simple} ($\alpha = 0.05$). 
We report paired effect sizes $\Delta$ with 95\% bootstrap CIs (10,000 resamples), plus exploratory contrast \textbf{Comp 5} (\astH\ vs. \lineH).
